Section 3

GitHub AST & Code Telemetry Scope

CareerPath AI features a specialized Two-Factor Skill Verification Moat. When students link their GitHub profile or click “Auto-Detect Skills”, our backend inspects code repositories to substantiate claimed proficiencies.

What We DO Scan:
  • Public repository metadata (names, primary language tags, stars, forks).
  • Public commit timestamps and commit frequency to verify continuous learning.
  • Abstract Syntax Tree (AST) structure of public code to verify framework usage (e.g. React components, Express routes, SQL queries).
Strict Negative Covenant:
  • NO access to private repositories or organization memberships.
  • NO reading or logging of sensitive files (`.env`, private keys, secrets, credentials).
  • NO source code cloning or persistent retention of repository source files on our servers.

GitHub authentication uses scoped OAuth tokens or public REST API endpoints with the minimum necessary read-only permissions. You can disconnect your GitHub sync at any time from the Student Dashboard.

Section 4

Single Resume & Document Storage

CareerPath AI maintains an architectural principle of One Dedicated Resume per Student Account to prevent resume duplication, stale document versions, and cloud storage leakage.

  • Binary Magic-Byte Inspection: Uploaded files are inspected in-memory for signature bytes (`%PDF-`, `PK\x03\x04` for DOCX) to reject disguised binary executables or malicious payloads.
  • Cloud Storage & Asset Destruction: Resume files are stored in an encrypted Cloudinary container. When you upload a replacement resume, our server issues a transactional destruction call (`cloudinary.uploader.destroy`), permanently wiping the previous document from the cloud.
  • Strict Non-Sale Covenant: Your resume, contact details, and academic transcripts are never sold, leased, or monetized with data brokers, marketing agencies, or unauthenticated aggregators.
Section 5

BYOK (Bring Your Own Key) Isolation Guarantee

For advanced users who prefer to use their personal API keys (such as custom Groq, OpenAI, or Google Gemini credentials) in the AI Career Mentor Drawer or Mock Interview Chamber:

Client-Side Isolation Guarantee

User-supplied API keys are stored strictly within your local browser storage (`window.localStorage`). They are NEVER transmitted to, received by, stored in, or logged on CareerPath AI backend servers. When in BYOK mode, requests dispatch directly from your client browser to the respective LLM provider endpoint.

Section 6

AI Data Processing & Zero Model Training

CareerPath AI harnesses enterprise artificial intelligence to deliver sub-300ms skill evaluations and realistic voice mock interviews. We uphold strict AI ethics and data boundaries:

AI Providers in Use:

We utilize the Groq Cloud API (running Meta Llama 3.3 70B Versatile on high-speed LPUs) and Google Gemini API (Gemini 2.5 Flash as multi-cloud failover) for ephemeral inference.

Zero Model Training:

Under enterprise API terms, your prompts, interview speech transcripts, and skill inputs are never used to train, retrain, or improve third-party AI models.

Furthermore, career matching and score calculations are 100% deterministic. We do not use LLMs to guess career matches; all scoring is computed via the transparent, mathematical 60/25/15 formula.

Section 7

Recruiter Talent Radar & Candidate Consent

The Recruiter Talent Radar is an enterprise feature allowing corporate employers to discover pre-assessed, proof-of-work engineering candidates:

  • Explicit Consent Required: Your profile and verified skill badges are visible to recruiters only if you have opted in via your Dashboard posture selector or submitted a 1-click application to an active job opening.
  • Search Posture Controls: You can modify your visibility at any time between:
    • actively_seeking: Full profile and resume visible to verified recruiters.
    • open_to_learning: Anonymized skills visible; contact details withheld until you approve outreach.
    • interviewing: Highlighted as in active discussion with recruiters.
  • Verified Recruiters Only: Recruiters must pass our 4-tier validation pipeline (corporate domain check, MX record probe, live website validation, and OTP verification) before accessing candidate radars.

WhatsApp Automation & Mobile Communications

Section 9

User Rights & Data Erasure (DPDP Act 2023)

Under Chapter III of the Digital Personal Data Protection Act 2023, you possess explicit rights regarding your personal data:

Right to Access:
Request a complete summary of all personal data, skill matrices, and assessment records held by CareerPath AI.
Right to Correction:
Update inaccurate academic details, refresh GitHub synchronization, or amend contact phone numbers.
Right to Erasure:
Trigger a complete cascade purge of your account, deleting database records, cloud resumes, and assessment logs.
Right of Grievance Redressal:
File a formal complaint with our designated Grievance Officer if any privacy request is unfulfilled.

To exercise your right to data erasure or export, navigate to Account Settings in the Dashboard or email the Grievance Desk at parthpatil@careerpath.is-local.org (or WhatsApp: +91 74990 85045). Requests are fulfilled within 7 business days.

Section 10

Data Retention & Storage Boundaries

Your data is stored in secure, SOC 2 compliant cloud facilities provided by Supabase PostgreSQL (hosted on AWS Mumbai / Frankfurt with SSL/TLS encryption enforced) and Render Cloud.

  • Active Accounts: Maintained for the duration of your academic and job search lifecycle.
  • Inactive Account Policy: Accounts inactive for $>365$ consecutive days receive automated streak notices before being scheduled for anonymization.
  • Skill Evidence Expiry (180-Day Rule): To prevent skill staleness, verified badges must be refreshed through quarterly milestone check-ins.
