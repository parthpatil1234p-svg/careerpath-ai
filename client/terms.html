Section 3

Strict Anti-Cheating & Exam Integrity Policy

The value of a CareerPath AI Verified Skill Certificate depends entirely on its rigorous, untampered validity. Any attempt to circumvent platform evaluation mechanisms is treated as academic fraud and a material breach of this Agreement.

3.1 Prohibited Fraudulent Conduct
  • Bot Automation & Script Injection: Using headless browsers (Puppeteer, Selenium), script-injected DOM manipulation, auto-clickers, or automated HTTP replay scripts to answer assessment questions or artificially complete weekly roadmap tasks.
  • Video Chamber Scrub Bypasses: Tampering with YouTube player iframe postMessage events, fast-forwarding through anti-scrub learning modules, or injecting false playback completion timestamps. Learning sessions require verifiable watch duration before milestone testing unlocks.
  • GitHub Telemetry Falsification: Submitting fake Git commit histories, creating artificial commits using backdated scripts, claiming unauthorized third-party repositories, or submitting empty boilerplate repositories to inflate the GitHub AST telemetry score.
  • Impersonation & Collusion: Having an unauthorized third party take weekly milestone examinations, sharing active question pools, or running multi-monitor remote screen-share exploits during proctored tests.
3.2 The 3-Strike Proctoring Protocol

During Weekly Milestone Examinations, CareerPath AI activates real-time client and server proctoring telemetry:

30-Min Server Clock

The test countdown clock is synchronized with server-side timestamps. Client-side clock manipulation has zero effect.

Tab Blur Tracking

Switching browser tabs, minimizing the window, or activating external software triggers an instant strike warning on screen.

3rd Strike Disqualification

Accumulating 3 strikes instantly locks the test session, records a failing grade (0%), and reports the infraction to the telemetry ledger.

Penalties for Breach: Violation of this Section 3 results in immediate, non-negotiable sanctions: permanent revocation of all earned certificates, deletion of verified radar rankings, locking of the career roadmap, and public invalidation on the SHA-256 verification ledger.

System Invariants & Abuse Prevention

To preserve database performance, eliminate fraud, and enforce authentic career commitment, CareerPath AI enforces architectural invariants:

  • 7-Day Route Abandonment Cooldown: When a student selects a career track and generates an active roadmap, switching or abandoning the target career is rate-limited by a 7-day programmatic cooldown. This prevents superficial route churn and preserves authentic telemetry.
  • Single Active Resume Invariant: Students may maintain only one active resume document on the platform. Uploading a revised PDF automatically and transactionally purges the previous file and its Cloudinary assets.
  • API Rate-Limiting: High-frequency requests, automated scraping, or concurrent hammering of assessment endpoints or AI chat channels trigger HTTP 429 (Too Many Requests) throttles. Continued abuse results in IP-range firewall blocking.
