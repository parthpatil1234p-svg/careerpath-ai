### Step 1. Authentication (`/login.html`)
1. Click **Get Started** from the landing page.
2. Select "Register here" and enter dummy User details (e.g. `judge@example.com`).
3. Press **Register**. Observe fast Glassmorphism auto-redirect into `/assessment.html`.

### Step 2. Profile & Gap Collection (`/assessment.html`)
1. Select "Third Year" from the Dropdown.
2. Filter through the **Interests** (tag "Web Development").
3. Assign Proficiencies natively toggling SLIDERS alongside skills natively (e.g., HTML = `Lvl 5`, React = `Lvl 2`).
4. Press **Save Assessment**.
5. Once "Assessment saved successfully." flashes, Click the actively unlocked `Career recommendations` button.

1. Observe 3 ranked Career Cards explicitly demonstrating deterministic JSON routing from algorithm logic (`Score Breakdowns = 60/25/15 rules`).
2. Highlight skill logic mapping (e.g. Green Tags show matched abilities, Red tags indicate exactly what the Roadmap will construct).
3. Select **Build My Roadmap**. Native duration modal renders. Choose `8 Weeks`.

2. Physically select a Checkbox mapping to the gap detected previously.
3. Observe real-time API execution calculating progress percentage globally updating immediately in the upper-UI array!
